# Painel de Ponto: instaladores

Aqui ficam só as versões do **Painel de Ponto**, o app da bandeja do Windows que acompanha o ponto no Kairos e as horas no Orbit/Timeflow. O código não fica neste repositório.

## Instalar

1. Baixe o `Painel de Ponto Setup X.Y.Z.exe` da [última versão](https://github.com/karolynelima/painel-ponto-versoes/releases/latest).
2. Se aparecer "O Windows protegeu o computador", clique em **Mais informações** › **Executar assim mesmo**.
3. Pronto: o ícone aparece perto do relógio. Entre no Kairos e no Orbit na primeira vez.

Depois disso, o app se atualiza sozinho quando sai versão nova.
